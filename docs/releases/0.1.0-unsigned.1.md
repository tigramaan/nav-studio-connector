# UMEC Nav Studio Connector 0.1.0 — unsigned bootstrap release

This public prerelease establishes the exact desktop package forms that the project intends to sign after SignPath Foundation onboarding.

> **Windows signing status:** the Windows executable and installer in this prerelease are **not digitally signed**. Windows may show an Unknown publisher or SmartScreen warning. Verify the SHA-256 value before running a file. Production releases remain blocked until Authenticode signing and timestamp verification succeed.

## What the connector does

UMEC Nav Studio Connector discovers `_umec-nav._tcp.local.` services on the local network, inspects the selected Nav Studio TLS certificate, requires an independently verified SHA-256 fingerprint or valid signed device identity receipt, installs only explicitly authorized trust, verifies HTTPS readiness, and opens Studio in the default browser. It includes a guided GUI and a versioned JSON CLI for automation agents.

## Install and remove

Windows: run the per-user setup executable. Remove the application later through **Settings → Apps → Installed apps → UMEC Nav Studio Connector → Uninstall**. The standalone executable does not install the application.

Ubuntu DEB:

```bash
sudo apt install "./UMEC Nav Studio Connector_0.1.0_amd64.deb"
sudo apt remove umec-nav-studio-connector
```

Ubuntu AppImage:

```bash
chmod +x "UMEC Nav Studio Connector_0.1.0_amd64.AppImage"
./"UMEC Nav Studio Connector_0.1.0_amd64.AppImage"
```

## Safety and privacy

mDNS is treated only as an untrusted candidate source. An unknown certificate is never silently accepted. The connector has no maintainer-operated telemetry or cloud backend and contains no robot SSH credentials or private signing material.
