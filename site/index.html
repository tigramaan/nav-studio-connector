One guided workflow

Everything needed between discovery and a trusted browser session.

01

Local discovery

Finds compatible Nav Studio services on the LAN with a bounded search. A guarded HTTPS URL remains available as a fallback.

02

Identity before trust

Shows the full SHA-256 fingerprint and requires explicit authorization. Signed device identity receipts are verified against a pinned public root.

03

Human and agent ready

Includes a guided desktop interface and a versioned JSON CLI contract for automation agents, with deterministic errors and sanitized diagnostics.

Designed around an untrusted LAN

Discovery is a hint.
Identity is the decision.

mDNS records, host names, URLs, certificates, and external responses are treated as untrusted input. The connector fails closed at every trust boundary.
